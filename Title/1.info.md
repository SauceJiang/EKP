## Shared Project Information and Guidelines

### Files in This Folder
- 2.*.md: project descriptions. The suffix after "_" indicates the contact initials.
- 1.*.md: shared information and templates used by all projects.
- 0.*.md: internal batch-generation artifacts; students can ignore.

### Project Structure
Each project follows a standardized template with the following sections:
- Introduction (Background, Learning Objectives, Prerequisites)
- Problem Statement (Technical Description, Key Challenges, Expected Outcomes)
- Data Description
- Methodology
- Evaluation
- Deliverables
- Timeline
- Resources
- Grading Criteria
- Submission Guidelines

### Standard Timeline
All projects follow approximately a 10-week schedule:
- Week 1-2: Data preprocessing and exploration
- Week 3-6: Model implementation
- Week 7-8: Evaluation and analysis
- Week 9-10: Report writing and presentation

### Common Deliverables
For all projects, students must submit:
1. Code Implementation
   - Well-documented source code
   - Data preprocessing scripts
   - Analysis notebooks
2. Analysis Report
   - Methodology description
   - Results and discussion
   - Performance evaluation
   - Results Visualization
   - Figures and plots
   - Performance metrics
3. Final Presentation
   - 15-minute presentation
   - Slides in PDF format

### Grading Criteria
All projects are evaluated using the following weighted criteria:
- Implementation quality (30%)
  - Code correctness
  - Documentation quality
  - Reproducibility
- Analysis depth (30%)
  - Methodology understanding
  - Results interpretation
  - Comparative analysis
- Report clarity (20%)
  - Organization
  - Writing quality
  - Visual presentation
- Innovation (20%)
  - Novel approaches
  - Creative solutions
  - Bonus questions

### Submission Guidelines
1. Code Repository Requirements
   - GitHub repository with clear structure
   - README.md with setup instructions
   - Requirements.txt or environment.yml
   - Well-documented code and reproducible scripts
   - Example usage demonstrations

2. Report Format
   - R Markdown or Python Notebook format
   - Following provided template
   - Maximum 20 pages
   - Including figures and tables
   - Including code and data, except the data provided to you
   - Complete references

3. Presentation Format
   - 10-minute time limit
   - PPT slides
   - Live demonstration if applicable
   - Q&A preparation

### Skill Objectives
Technical skills to be developed across all projects:
- Python / R programming
- Python / R visualization
- Understanding of statistical learning principles
- Exploration of ai4science literatures
- Experience with data analysis
- Experience with agentic coding

### Recommended Tools and Resources
Standard technical stack:
- Python scientific computing libraries
  - NumPy
  - Pandas
  - Scikit-learn
- Version control
  - Git
  - GitHub
- Development environment
  - Jupyter Notebook
  - Trae or Cursor IDE
  - Large Language Model for Coding
